## About

[DawnSounds](https://www.dawnsounds.tech) is an interactive soundboard and audio guessing quiz web application for Mobile Legends: Bang Bang players and voice line enthusiasts. 

Built with a dark, gaming-focused interface, it allows players to explore character audio, test their hero audio recognition skills in competitive quiz modes, and track their daily streaks on a global leaderboard.

## Features

### 🔊 Hero Voice Line Soundboard
- **133 Heroes Roster** — Complete collection with high-quality voice audio playback.
- **Smart Filtering & Search** — Search by hero name or quote, filter by role/lane, and sort alphabetically.
- **Display Modes** — Switch seamlessly between Grid and List view modes.
- **Interactive Audio Tools** — Quick audio controls with random quote player and built-in speech synthesis fallback.

### 🎮 Interactive Audio Quiz
- **Classic (Daily Challenge)** — 10 rounds of audio guessing with the same daily question set for everyone. Resets at local midnight with a live countdown timer, daily streak tracking, grid results, and easy result sharing.
- **Survival Mode** — Endless audio quiz rounds with a 3-heart system for unlimited replayability.
- **Quit / Refresh Protection** — Safeguards active quiz runs against accidental navigation or page reloads.

### 🏆 Global & Local Leaderboards
- **Global Leaderboard** — Real-time high-score sync powered by Supabase with anti-cheat score validation.
- **Offline Fallback** — Automatically saves scores to local storage if offline or running without external services.
- **Flame Streak Tracking** — Displays top player best streaks alongside full date timestamps.

### 🌐 Internationalization (i18n)
- **Multi-Language UI** — Supports English (default), Tagalog, and 简体中文 (Simplified Chinese).
- **Type-Checked Translations** — Fully checked against the primary language schema for complete key coverage.
